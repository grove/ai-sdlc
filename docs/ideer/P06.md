# P06 Skille behov fra foreslått løsning

<a id="p06"></a>

- **Steg:** [Problem](../steg/problem.md)
- **Temaområde:** [Brukerbehov og virksomhetsproblemer](../steg/problem.md#p-kategori-1)
- **Arbeidsform:** Rådgivning
- **Særlig relevant for:** Produktutvikling, Plattform, Pakkeløsninger, Dokumenter og beslutninger

## Muligheten

KI kan gjennomgå bestillinger som allerede angir en funksjon eller teknologi, og formulere problemet som ønsket endring for en bruker eller virksomhet. Den kan peke på manglende dokumentasjon og spørsmål som må besvares før behovet er avklart.

## Grunnlag

Bestillinger, forretningsmål, brukerbeskrivelser, tilgjengelige effektdata og beslutninger som forklarer hvorfor saken ble opprettet.

## Forutsetninger

Tilgang til bestiller, forståelige virksomhetsmål og rom for å undersøke problemet før løsningsvalg.

## Eksempel og leveranse

Bestillingen «bygg en chatbot» omformuleres til problemer med å finne gjeldende rutiner. Leveransen er et behovsnotat med bevis, usikkerhet og avgrensning.

## Kontroll

Bestiller og berørte brukere godkjenner omformuleringen; KI får ikke erstatte eksplisitte krav med egne antakelser.

## Mål effekt

Mål avklaringstid og andel bestillinger med bekreftet behov, sammen med senere misforståelser og endret omfang.
