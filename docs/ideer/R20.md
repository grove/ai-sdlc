# R20 Forbered støtteapparatet på forventede spørsmål

<a id="r20"></a>

- **Steg:** [Produksjon](../steg/produksjon.md)
- **Temaområde:** [Driftsberedskap og mottak](../steg/produksjon.md#r-kategori-3)
- **Arbeidsform:** Utforming
- **Særlig relevant for:** Forvaltning, Produktutvikling, Dokumenter og beslutninger

## Muligheten

KI kan omsette releaseinformasjon, kjente begrensninger og testfunn til en støttespesifikk kunnskapspakke. Den kan foreslå spørsmål, avklaringssteg og eskaleringsregler som gjelder den nye løsningen. Dette hjelper støttepersonell med å gi konsistente svar ved innføring uten å måtte tolke utviklernes rå endringshistorikk.

## Grunnlag

Godkjent releaseinformasjon, brukerforløp, kjente problemer, feilkoder, støtteprosedyrer og avklart grense mellom førstelinje og faglig eskalering.

## Forutsetninger

Støttekanalene må ha eiere og godkjent kunnskapsgrunnlag, med klare grenser for hvilke råd de kan gi.

## Eksempel og leveranse

For endret innlogging lager KI et støtteark som skiller feil klientversjon, manglende tilgang og tjenestefeil, med godkjente råd og nødvendige eskaleringsopplysninger.

## Kontroll

Støtteansvarlig og fageier godkjenner svarene. Råd skal ikke oppfordre til å dele hemmeligheter, omgå tilgangskontroll eller utføre uautoriserte tiltak.

## Mål effekt

Tid til støtteapparatet er klart, sammen med feilaktige standardsvar, unødvendige eskaleringer og henvendelser uten tilgjengelig godkjent veiledning.
