# K21 Varsle om foreldet kontekst

<a id="k21"></a>

- **Steg:** [Kontekst](../steg/kontekst.md)
- **Temaområde:** [Kilder data og arbeidsflate](../steg/kontekst.md#k-kategori-3)
- **Arbeidsform:** Avgrenset utførelse
- **Særlig relevant for:** Integrasjon, Plattform, Dokumenter og beslutninger

## Muligheten

KI kan sammenligne kildeversjoner og endringshistorikk med kontekstpakker som allerede er i bruk. Den kan foreslå hvilke pakker som må oppdateres eller sperres, slik at agenter ikke fortsetter på krav og grensesnitt som har blitt endret.

## Grunnlag

Versjonerte kontekstpakker, kildeidentiteter, endringshendelser, eiere og avtalt gyldighet.

## Forutsetninger

Kildeversjoner og koblinger mellom kontekstpakker og oppdrag må kunne registreres og leses.

## Eksempel og leveranse

Når et API-skjema endres, lager KI en liste over berørte agentoppdrag og foreslår nye utdrag, med tydelig markering av endret kontrakt.

## Kontroll

Eier godkjenner semantiske oppdateringer; aktive oppdrag skal følge en avtalt stopp eller gjenopptakelsesregel ved kritiske endringer.

## Mål effekt

Andel oppgaver med foreldet kontekst og oppdateringstid, balansert med unødvendige avbrudd og oversette endringer.

## Bruk ideen i prosjektet

Avtal hvilke kilder, tilganger og kvalitetskrav som gjelder for den konkrete oppgaven. Mål både tiden til brukbar kontekst og etterarbeid som skyldes mangler eller feil i grunnlaget.
