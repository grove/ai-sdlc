# A15 Implementere rettelser for validerte sikkerhetsfunn

<a id="a15"></a>

- **Steg:** [Agentutførelse](../steg/agentutforelse.md)
- **Temaområde:** [Vedlikehold og modernisering](../steg/agentutforelse.md#a-kategori-2)
- **Arbeidsform:** Avgrenset utførelse
- **Særlig relevant for:** Regulert arbeid, Forvaltning, Produktutvikling

## Muligheten

En agent kan utarbeide konkrete rettelser for bekreftede sikkerhetsproblemer og følge godkjente mønstre for kontroll av input og tilgang. Den kan levere små endringer og tilhørende tester, slik at funn raskere blir omgjort til vurderbart arbeid.

## Grunnlag

Validert funn, berørt kode, trusselbeskrivelse, godkjent sikkerhetsmønster og eksplisitte akseptansekriterier.

## Forutsetninger

En bekreftet problemforståelse og uavhengige tester eller faglig kontroll av det aktuelle sikkerhetskravet.

## Eksempel og leveranse

En manglende serverkontroll i et API rettes med eksisterende autorisasjonskomponent; agenten leverer kode og negative testtilfeller for uautoriserte roller.

## Kontroll

Sikkerhets og kodeeier bekrefter rettelsen; agenten må ikke dempe varsler, fjerne tester eller omklassifisere funnet for å oppnå godkjenning.

## Mål effekt

Tid fra bekreftet funn til godkjent rettelse, sammen med gjenåpnede funn og funksjonelle regresjoner.

## Bruk ideen i prosjektet

Avtal leveranse, verktøy, filområder, stoppsignaler og ansvar for gjennomgang. Ta med oppsett, menneskelig oppfølging og senere feilretting når forsøket vurderes.
