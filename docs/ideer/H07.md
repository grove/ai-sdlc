# H07 Sammenligne arkitekturvalg mot konkrete scenarioer

<a id="h07"></a>

- **Steg:** [Hypotese](../steg/hypotese.md)
- **Temaområde:** [Alternativer og virkemåte](../steg/hypotese.md#h-kategori-1)
- **Arbeidsform:** Rådgivning
- **Særlig relevant for:** Integrasjon, Plattform, Eldre systemer, Embedded og OT

## Muligheten

KI kan formulere arkitekturalternativer og vurdere dem mot forhåndsdefinerte endrings-, drifts- og feilscenarioer. Den kan gjøre bytteforhold tydelige og foreslå hvilke tekniske prøver som bør gjennomføres, slik at beslutningen bygger på prosjektets behov fremfor generelle arkitekturpreferanser.

## Grunnlag

Funksjonelle krav, kvalitetskrav, arkitekturgrenser, lastforventninger, kompetanse og relevante scenarioer for vedlikehold, feil og videre utvikling.

## Forutsetninger

Eksplisitte kvalitetskrav, oversikt over eksisterende systemgrenser og fagpersoner som kan vurdere drifts- og endringsscenarioer.

## Eksempel og leveranse

Teamet vurderer synkron API eller hendelsesflyt for ordrebehandling. KI lager et ADR-utkast med scenarioer, usikre forhold og foreslåtte tekniske avklaringer før valg.

## Kontroll

Arkitekt og driftseier validerer realisme, avhengigheter og sikkerhet; påstander om ytelse og kostnad krever måling eller bekreftede kilder.

## Mål effekt

Mål tid til begrunnet arkitekturvalg, sammen med oversette kvalitetskrav, prøvekostnad og behov for senere omvalg.

## Bruk ideen i prosjektet

Gjør ideen til et avgrenset forsøk med hypotese, sammenligningsgrunnlag og beslutningsregler. Registrer forventet verdi, kontrollbehov og usikkerhet før resultatene foreligger.
