# A26 Forbedre prosessen for bygg og levering

<a id="a26"></a>

- **Steg:** [Agentutførelse](../steg/agentutforelse.md)
- **Temaområde:** [Plattform og øvrige leveranser](../steg/agentutforelse.md#a-kategori-4)
- **Arbeidsform:** Utforming
- **Særlig relevant for:** Plattform, Forvaltning, Regulert arbeid

## Muligheten

En agent kan utarbeide pipelineendringer som standardiserer bygg, test og artefakthåndtering. Den kan redusere gjentatt manuelt oppsett og synliggjøre avhengigheter, men må bevare alle obligatoriske porter og tilganger i organisasjonens leveranseprosess.

## Grunnlag

Eksisterende pipeline, kjørelogger, godkjente steg, artefaktkrav og regler for hemmeligheter og godkjenning.

## Forutsetninger

Versjonert pipelinekonfigurasjon og en trygg måte å prøve endringer uten å påvirke produksjonsleveranser.

## Eksempel og leveranse

Et prosjekt får forslag til gjenbrukbar byggjobb og mer presis cachebruk; agenten leverer konfigurasjon og sammenligning av hvilke steg som utføres.

## Kontroll

Pipelineeier kontrollerer sikkerhet og gateintegritet; agenten kan ikke fjerne feilsjekker eller utvide credentials for å gjøre bygget grønt.

## Mål effekt

Tid og kostnad per verifisert bygg, balansert med ustabile kjøringer, manglende kontroller og cachefeil.

## Bruk ideen i prosjektet

Avtal leveranse, verktøy, filområder, stoppsignaler og ansvar for gjennomgang. Ta med oppsett, menneskelig oppfølging og senere feilretting når forsøket vurderes.
