# P24 Koble feltfeil til utstyr og driftsforhold

<a id="p24"></a>

- **Steg:** [Problem](../steg/problem.md)
- **Temaområde:** [Teknologi data og drift](../steg/problem.md#p-kategori-3)
- **Arbeidsform:** Rådgivning
- **Særlig relevant for:** Embedded og OT, Mobil og klient, Forvaltning, Regulert arbeid

## Muligheten

KI kan sammenstille feilrapporter fra installert utstyr, firmwareversjoner og miljøforhold for å finne problemkandidater som ikke oppstår i laboratoriet. Den kan fremheve forskjeller mellom utstyrsgrupper og hva som må undersøkes videre med sikker og kontrollert testing.

## Grunnlag

Godkjente feltrapporter, utstyrsversjoner, firmware, driftsbetingelser, vedlikeholdshistorikk og metadata om hvordan feilene faktisk ble registrert.

## Forutsetninger

Sporbar kobling mellom utstyr og versjon, tilstrekkelige feltdata og avklart ansvar for sikker testing.

## Eksempel og leveranse

Sensorer mister kommunikasjon bare i enkelte installasjoner etter oppdatering. KI lager en sammenligningsoversikt over utstyr, versjoner og forhold som krever videre testing.

## Kontroll

Ansvarlig ingeniør bekrefter datakvalitet og mulig sikkerhetskonsekvens; mønsteret gir undersøkelseshypoteser, ikke tillatelse til automatiske feltendringer.

## Mål effekt

Mål tid til reproduserbart problem, sammen med feilklassifisering, oversette sikkerhetsforhold og behov for ekstra feltbesøk.
