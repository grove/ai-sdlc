# P25 Synliggjøre kostnaden ved dagens problem

<a id="p25"></a>

- **Steg:** [Problem](../steg/problem.md)
- **Temaområde:** [Kostnader risiko og prioritering](../steg/problem.md#p-kategori-4)
- **Arbeidsform:** Rådgivning
- **Særlig relevant for:** Produktutvikling, Plattform, Pakkeløsninger, Forvaltning

## Muligheten

KI kan bygge en enkel kostnadsmodell fra dokumenterte tidsprøver, hendelser og ressurspriser. Den kan skille faktisk utbetaling, frigjørbar kapasitet og usikre konsekvenser, slik at prosjekteier forstår størrelsesorden og hvilke antakelser som må undersøkes før prioritering.

## Grunnlag

Representative tidsmålinger, saksvolum, fakturerte kostnader, interne kalkylesatser og dokumenterte bruker- eller driftskonsekvenser fra problemet.

## Forutsetninger

Avklarte kalkyleprinsipper, representative arbeidsprøver og tilgang til økonomiansvarlig som kan vurdere forutsetningene i estimatet.

## Eksempel og leveranse

Manuell avstemming krever faste timer hver måned og gir forsinkelser. KI leverer et kostnadsestimat med beregninger, intervaller, kilder og uttrykkelige antakelser.

## Kontroll

Økonomi- og prosesseier godkjenner antakelser; tidsverdi og verdien av samme leveranser skal ikke telles to ganger.

## Mål effekt

Mål tid til etterprøvbart kostnadsgrunnlag, sammen med beregningsfeil og avvik fra senere observerte faktiske kostnader.
