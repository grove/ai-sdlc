# A01 Implementere en avgrenset produktfunksjon

<a id="a01"></a>

- **Steg:** [Agentutførelse](../steg/agentutforelse.md)
- **Temaområde:** [Produkt og brukerflater](../steg/agentutforelse.md#a-kategori-1)
- **Arbeidsform:** Avgrenset utførelse
- **Særlig relevant for:** Produktutvikling, Integrasjon, Eldre systemer

## Muligheten

En agent kan implementere en sammenhengende, liten funksjon fra godkjente krav til kode, relevante tester og dokumentasjon. Den kan følge eksisterende mønstre og levere en vurderbar endring, slik at utvikleren bruker mer tid på faglige valg og kontroll.

## Grunnlag

Avklart brukerhistorie, kontrakter, kodebase, godkjente mønstre, testgrunnlag og eksplisitte akseptansekriterier.

## Forutsetninger

Avgrenset endringsområde, fungerende testmiljø og en agent som bare kan skrive i autorisert arbeidsflate.

## Eksempel og leveranse

For en ordreoversikt implementerer agenten filtrering i API og grensesnitt og leverer en PR med diff, kjørte tester og kjente begrensninger.

## Kontroll

Utvikler gjennomgår design og kode; uavhengig CI bekrefter testresultater før endringen får gå videre mot produksjon.

## Mål effekt

Samlet tid til godkjent funksjon, inkludert gjennomgang og retting, balansert med feil etter levering.

## Bruk ideen i prosjektet

Avtal leveranse, verktøy, filområder, stoppsignaler og ansvar for gjennomgang. Ta med oppsett, menneskelig oppfølging og senere feilretting når forsøket vurderes.
