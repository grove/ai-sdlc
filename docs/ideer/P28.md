# P28 Synliggjøre usikkerhet som hindrer prosjektbeslutninger

<a id="p28"></a>

- **Steg:** [Problem](../steg/problem.md)
- **Temaområde:** [Kostnader risiko og prioritering](../steg/problem.md#p-kategori-4)
- **Arbeidsform:** Rådgivning
- **Særlig relevant for:** Eldre systemer, Data og analyse, Integrasjon, Regulert arbeid

## Muligheten

KI kan lese beslutningsgrunnlag og prosjektplaner for å skille dokumenterte forhold fra antakelser. Den kan peke ut usikkerhet om data, avhengigheter eller gjennomførbarhet som stopper fremdrift, slik at prosjektet kan formulere et tydelig undersøkelsesproblem fremfor å gjette.

## Grunnlag

Beslutningsnotater, risikologg, planer, åpne spørsmål og dokumenterte svar fra fagpersoner, leverandører eller berørte tjenesteeiere.

## Forutsetninger

Tilgang til gjeldende beslutningsgrunnlag, kildeversjoner og personer som kan bekrefte hvilke opplysninger som mangler.

## Eksempel og leveranse

En migrering står stille fordi datavolum og nedetidsbehov er ukjent. KI lager et usikkerhetskart med kildegrunnlag, eiere og konkrete manglende avklaringer.

## Kontroll

Prosjektleder og fagansvarlige bekrefter hva som faktisk er uavklart; fravær i dokumentene betyr ikke nødvendigvis manglende kunnskap.

## Mål effekt

Mål tid til tydelig undersøkelsesproblem, sammen med ventende beslutninger og feilaktig klassifiserte antakelser i grunnlaget.
