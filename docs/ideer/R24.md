# R24 Klargjør kontrollert publisering av modeller og dataprodukter

<a id="r24"></a>

- **Steg:** [Produksjon](../steg/produksjon.md)
- **Temaområde:** [Driftsberedskap og mottak](../steg/produksjon.md#r-kategori-3)
- **Arbeidsform:** Utforming
- **Særlig relevant for:** KI i produktet, Data og analyse, Regulert arbeid

## Muligheten

KI kan samle modellversjon, datasettavhengigheter, evalueringsbevis og bruksgrenser i en publiseringspakke. Den kan kontrollere at ruting og fallback er planlagt før aktivering. Dette støtter overlevering av løsninger der resultatet avhenger av både programvare, data og modellkonfigurasjon som må kunne spores sammen.

## Grunnlag

Godkjent modell eller dataprodukt, registeridentitet, evalueringsresultater, datakontrakter, rutingregler, fallback og tillatt bruksområde for mottakende tjenester.

## Forutsetninger

Modeller og data må være versjonert og godkjent, med eksplisitte bruksgrenser og kontrollerbar mekanisme for aktivering og tilbakeføring.

## Eksempel og leveranse

For en prognosetjeneste lager KI en aktiveringspakke med modellversjon, siste godkjente datasett, fallback til tidligere metode og tydelige grenser for hvilke kunder som omfattes.

## Kontroll

Modell- og dataeier godkjenner publisering. KI kan ikke utvide bruksområdet eller bytte modell automatisk uten ny evaluering og uttrykkelig autorisasjon.

## Mål effekt

Tid til sporbar modellaktivering, sammen med versjonsfeil, manglende fallback og bruk utenfor de godkjente data eller beslutningsgrensene.
