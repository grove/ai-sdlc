# P21 Beskrive datakvalitetsproblemer med faktisk konsekvens

<a id="p21"></a>

- **Steg:** [Problem](../steg/problem.md)
- **Temaområde:** [Teknologi data og drift](../steg/problem.md#p-kategori-3)
- **Arbeidsform:** Rådgivning
- **Særlig relevant for:** Data og analyse, Pakkeløsninger, Integrasjon, Regulert arbeid

## Muligheten

KI kan sammenstille datakontroller og faglige klager for å vise hvor feil i data påvirker beslutninger eller prosesser. Den kan koble tomme felter, duplikater og uklare begreper til berørte leveranser, slik at dataproblemer får tydelig eier og verdi.

## Grunnlag

Dataprofiler, kvalitetstester, begrepskatalog, avstemmingsfunn og beskrivelser av beslutningene eller prosessene som bruker de aktuelle dataene.

## Forutsetninger

Metadata eller godkjente dataprøver, dokumenterte kvalitetsregler og navngitte eiere for data og begreper.

## Eksempel og leveranse

Ulike definisjoner av aktiv kunde gir motstridende rapporter. KI lager et problemnotat som knytter definisjoner, kilder, rapporter og beslutningskonsekvenser sammen for gjennomgang.

## Kontroll

Dataeier og fagansvarlig validerer definisjoner og konsekvens; rå personopplysninger skal ikke deles bare for å forklare problemet.

## Mål effekt

Mål tid til bekreftet dataproblem, sammen med avstemmingsfeil, feilaktige kvalitetsfunn og berørte forretningsbeslutninger over tid.
