# H17 Modellere netto tidsgevinst og total kostnad

<a id="h17"></a>

- **Steg:** [Hypotese](../steg/hypotese.md)
- **Temaområde:** [Økonomi kapasitet og arbeidsmåter](../steg/hypotese.md#h-kategori-3)
- **Arbeidsform:** Utforming
- **Særlig relevant for:** Produktutvikling, Plattform, Dokumenter og beslutninger, Pakkeløsninger

## Muligheten

KI kan utforme en kalkyle som inkluderer sparte arbeidsoppgaver, nye kontrolloppgaver, lisenser, modellbruk og løpende vedlikehold. Den kan skille frigjort kapasitet fra faktiske kostnadskutt, slik at hypotesen om effektivisering undersøkes på hele arbeidsflyten og ikke bare ved produksjon av utkast.

## Grunnlag

Baseline for arbeidstid, forventet oppgavevolum, aktuelle priser, opplæringsbehov og anslag for review, feilretting og agentdrift i forsøket.

## Forutsetninger

Avklarte kalkylesatser, dokumentert baseline og oppfølging av alle vesentlige kostnader gjennom hele forsøksperioden.

## Eksempel og leveranse

En dokumentagent lager raskt utkast, men krever faglig kontroll. KI leverer en kalkylemal som inkluderer begge aktivitetene og viser når forsøket gir netto nytte.

## Kontroll

Økonomi- og fagansvarlig kontrollerer forutsetninger; estimerte timer er kapasitetsverdi og skal ikke bokføres som kontantgevinst uten realisering.

## Mål effekt

Mål tid til komplett kostnadsmodell, sammen med manglende poster, dobbelttelling og avvik mot faktisk ressursbruk.
