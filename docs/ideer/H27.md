# H27 Sammenligne alternativer for trygg databruk

<a id="h27"></a>

- **Steg:** [Hypotese](../steg/hypotese.md)
- **Temaområde:** [Risiko og beslutningsregler](../steg/hypotese.md#h-kategori-4)
- **Arbeidsform:** Rådgivning
- **Særlig relevant for:** Regulert arbeid, Data og analyse, KI i produktet, Forvaltning

## Muligheten

KI kan strukturere løsningsalternativer med ulike dataflyter, som metadata, anonymiserte eksempler, syntetiske data eller godkjent lokal behandling. Den kan synliggjøre konsekvenser for nytte og målebarhet, slik at prosjektet undersøker løsninger innenfor avklarte data- og sikkerhetskrav.

## Grunnlag

Dataklassifisering, behandlingsformål, godkjente tjenester, krav til representativitet og beskrivelse av hvilke opplysninger agentoppgaven faktisk trenger.

## Forutsetninger

Oppdaterte dataregler, avklart behandlingsformål og tilgang til ansvarlige som kan kontrollere de faktiske dataflytene.

## Eksempel og leveranse

Supportanalyse inneholder persondata. KI lager et alternativnotat som sammenligner metadataanalyse, godkjent avidentifisering og behandling i avklart miljø med tilhørende begrensninger for forsøket.

## Kontroll

Personvern- og sikkerhetsansvarlig avgjør tillatt behandling; KI kan ikke bekrefte anonymitet, hjemmel eller leverandørvilkår på egen hånd.

## Mål effekt

Mål tid til godkjent dataalternativ, sammen med analysekvalitet, dataminimering og etterlevelse av avtalte behandlingsgrenser i piloten.

## Bruk ideen i prosjektet
