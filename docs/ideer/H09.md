# H09 Velge hovedmål og balanserende kvalitetsmål

<a id="h09"></a>

- **Steg:** [Hypotese](../steg/hypotese.md)
- **Temaområde:** [Eksperimenter og målegrunnlag](../steg/hypotese.md#h-kategori-2)
- **Arbeidsform:** Rådgivning
- **Særlig relevant for:** Produktutvikling, Plattform, Forvaltning, Dokumenter og beslutninger

## Muligheten

KI kan koble forbedringshypotesen til et begrenset sett av mål som dekker ønsket resultat og mulige bivirkninger. Den kan foreslå hvilke indikatorer som viser verdi, og hvilke som bare beskriver aktivitet, slik at forsøket unngår ensidig optimalisering.

## Grunnlag

Hypotese, virkningskjede, kvalitetskrav, kostnadsramme og tilgjengelige målekilder i produkt, utviklingsflyt, drift og teamets arbeidsmiljø.

## Forutsetninger

En avklart hypotese, kjente kvalitetskrav og innsikt i hvilke data teamet kan samle pålitelig.

## Eksempel og leveranse

En agent for testskriving får tid til godkjent testpakke som hovedmål. KI foreslår også funnrate, reviewtid og feil etter levering som kontrollmål.

## Kontroll

Hypoteseeier og kvalitetsansvarlig godkjenner målene; ikke bruk flere produserte tester eller mer KI-bruk som tilstrekkelig verdiindikator.

## Mål effekt

Mål tid til godkjent målsett, sammen med oversette bivirkninger, målebelastning og faktisk beslutningsnytte etter forsøket.

## Bruk ideen i prosjektet

Gjør ideen til et avgrenset forsøk med hypotese, sammenligningsgrunnlag og beslutningsregler. Registrer forventet verdi, kontrollbehov og usikkerhet før resultatene foreligger.
