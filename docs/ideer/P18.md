# P18 Koble gjentatte driftsproblemer til felles mønstre

<a id="p18"></a>

- **Steg:** [Problem](../steg/problem.md)
- **Temaområde:** [Teknologi data og drift](../steg/problem.md#p-kategori-3)
- **Arbeidsform:** Rådgivning
- **Særlig relevant for:** Forvaltning, Plattform, Integrasjon

## Muligheten

KI kan strukturere hendelsesrapporter og sammenholde symptomer, berørte tjenester og tidligere tiltak. Den kan finne tilbakevendende problemkandidater på tvers av enkelthendelser, slik at teamet undersøker varige forbedringer og oppdager tiltak som bare har dempet symptomene.

## Grunnlag

Hendelsesrapporter, tidslinjer, tjenestekart, logger med godkjent datainnhold og beskrivelser av tiltak som allerede er forsøkt.

## Forutsetninger

Tilgang til kvalitetssikrede hendelsesdata, tjenesteeierskap og en felles definisjon av symptomer og årsaker.

## Eksempel og leveranse

Flere nattlige alarmer handler om samme kø som fylles etter batchkjøring. KI lager et samlet problemkort med tidslinje og dokumenterte likheter.

## Kontroll

Tjenesteeier bekrefter hendelseskoblinger og teknisk forklaring; lik ordlyd eller tidspunkt er ikke tilstrekkelig årsaksbevis alene.

## Mål effekt

Mål tid til bekreftet gjentakende problem, sammen med hendelsesgjentakelse og feilaktig sammenslåtte hendelser i analysen.
