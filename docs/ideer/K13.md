# K13 Kartlegge dataflyt og personvernbehov

<a id="k13"></a>

- **Steg:** [Kontekst](../steg/kontekst.md)
- **Temaområde:** [Krav og oppgaveforståelse](../steg/kontekst.md#k-kategori-2)
- **Arbeidsform:** Utforming
- **Særlig relevant for:** Data og analyse, Regulert arbeid, Integrasjon

## Muligheten

KI kan foreslå hvilke data som behandles, hvor de flyter, og hvilke begrensninger som følger av godkjente interne regler. Kartet hjelper teamet å velge dataminimering og testgrunnlag, samtidig som juridiske avklaringer synliggjøres før utførelse.

## Grunnlag

Datamodeller, tjenestekoblinger, behandlingsoversikter, lagringsregler og godkjente eksempler uten unødvendige persondata.

## Forutsetninger

Datakilder som kan analyseres innen godkjent behandling og identifiserbare eiere for data og formål.

## Eksempel og leveranse

Før en kunderapport bygges, lager KI et dataflytkart som viser felter, mottakere, lagring og uavklarte spørsmål om formål og sletting.

## Kontroll

Personvern og dataeier bekrefter klassifisering og lovlig bruk; KI avgjør ikke behandlingsgrunnlag eller juridiske plikter.

## Mål effekt

Tid til avklart datagrunnlag, supplert med unødvendige felter, feilklassifisering og personvernavvik oppdaget senere.

Avtal hvilke kilder, tilganger og kvalitetskrav som gjelder for den konkrete oppgaven. Mål både tiden til brukbar kontekst og etterarbeid som skyldes mangler eller feil i grunnlaget.
