# H20 Inkludere feilkonsekvens i forbedringshypotesen

<a id="h20"></a>

- **Steg:** [Hypotese](../steg/hypotese.md)
- **Temaområde:** [Økonomi kapasitet og arbeidsmåter](../steg/hypotese.md#h-kategori-3)
- **Arbeidsform:** Rådgivning
- **Særlig relevant for:** Regulert arbeid, Embedded og OT, Data og analyse, Integrasjon

## Muligheten

KI kan strukturere mulige feilutfall og synliggjøre hvordan sannsynlighet, alvorlighet og gjenoppretting påvirker nytten av et tiltak. Den kan hjelpe teamet å planlegge nødvendige kvalitetsgrenser, slik at tidsbesparelse ikke vurderes isolert fra kostbar feilretting eller uakseptabel skade.

## Grunnlag

Risikovurdering, historiske hendelser, tilbakeføringskostnader, berørte brukere og virksomhetens grenser for hvilke feilkonsekvenser som kan aksepteres.

## Forutsetninger

Navngitt risikoeier, tilgang til relevante feilforløp og tydelige krav som ikke kan byttes mot tidsgevinst.

## Eksempel og leveranse

En migreringsagent sparer manuelt arbeid, men feil mapping kan gi store rettinger. KI lager scenarioer og kontrollpunkter som inngår i forsøksbeslutningen.

## Kontroll

Risikoeier fastsetter akseptgrenser; alvorlige sikkerhetskrav kan ikke oppveies av forventet økonomisk gevinst i en enkel kalkyle.

## Mål effekt

Mål tid til komplett risikohypotese, sammen med oversette feilutfall, kontrollkostnad og etterlevelse av avtalte kvalitetsgrenser.
