# P07 Finne underrepresenterte brukersituasjoner

<a id="p07"></a>

- **Steg:** [Problem](../steg/problem.md)
- **Temaområde:** [Brukerbehov og virksomhetsproblemer](../steg/problem.md#p-kategori-1)
- **Arbeidsform:** Rådgivning
- **Særlig relevant for:** Produktutvikling, Mobil og klient, Embedded og OT, Regulert arbeid

## Muligheten

KI kan sammenligne hvem som er omtalt i krav og innsiktsmateriale med de brukergruppene produktet skal støtte. Den kan synliggjøre svakt dekkede situasjoner, som sjelden bruk, ustabil forbindelse eller språkbehov, og foreslå målrettet videre innsiktsarbeid.

## Grunnlag

Målgruppebeskrivelse, eksisterende brukerinnsikt, krav, bruksstatistikk på forsvarlig aggregert nivå og kjente driftsforhold.

## Forutsetninger

Eksplisitt målgruppe, oversikt over eksisterende utvalg og mulighet for å hente reell supplerende innsikt.

## Eksempel og leveranse

En feltapp er bare undersøkt hos erfarne brukere med stabil dekning. KI lager et gapnotat for nyansatte, frakoblet bruk og alternative arbeidssituasjoner.

## Kontroll

Produkteier vurderer relevans og representativitet; KI-genererte personaer behandles som spørsmål og aldri som faktisk brukerforskning.

## Mål effekt

Mål tid til identifisert innsiktsgap, sammen med senere bekreftelse og kostnad ved irrelevant ekstra kartlegging.
