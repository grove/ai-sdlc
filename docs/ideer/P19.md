# P19 Finne kostbare og langsomme bruksforløp

<a id="p19"></a>

- **Steg:** [Problem](../steg/problem.md)
- **Temaområde:** [Teknologi data og drift](../steg/problem.md#p-kategori-3)
- **Arbeidsform:** Rådgivning
- **Særlig relevant for:** Produktutvikling, Plattform, Data og analyse, KI i produktet

## Muligheten

KI kan sammenholde profiler, sporingsdata og ressurskostnader for å identifisere operasjoner som er både langsomme eller dyre og viktige for brukerne. Den kan foreslå hvilke problemer som fortjener videre måling, uten å utlede årsak direkte fra samvariasjon.

## Grunnlag

Profiler, aggregerte traces, kostnadsfordeling, brukeroppgaver og kjente grenser for hva måledataene faktisk dekker i systemet.

## Forutsetninger

Sammenheng mellom tjeneste, kostnad og brukeroppgave samt måledata fra representative last- og tidsperioder.

## Eksempel og leveranse

En eksport bruker mye minne og skaper venting ved periodestenging. KI lager et prioritert problembilde med berørte forløp og forslag til etterprøving.

## Kontroll

Utvikler og tjenesteeier kontrollerer målingene, normaliserer for last og bekrefter brukerbetydning før tekniske årsaker konkluderes.

## Mål effekt

Mål tid til validert ytelsesproblem, sammen med kostnad per forløp, brukeropplevelse og feilaktige problemanbefalinger.
