# P12 Synliggjøre avbrudd og skjult arbeid

<a id="p12"></a>

- **Steg:** [Problem](../steg/problem.md)
- **Temaområde:** [Flaskehalser og arbeidsflyt](../steg/problem.md#p-kategori-2)
- **Arbeidsform:** Rådgivning
- **Særlig relevant for:** Forvaltning, Plattform, Produktutvikling

## Muligheten

KI kan kategorisere frivillige arbeidsprøver og registrerte hasteoppgaver for å beskrive arbeid som ikke vises i leveranseplanen. Den kan skille nødvendige avbrudd fra unødvendig omveksling mellom oppgaver og foreslå hvilke mønstre teamet bør undersøke nærmere.

## Grunnlag

Representative arbeidsprøver, hendelser, støtteoppgaver, teamets egne beskrivelser og regler for bruk av arbeidsmiljødata.

## Forutsetninger

Frivillig eller på annen måte avklart datainnsamling, teamaggregater og tilstrekkelig bredde i arbeidsutvalget.

## Eksempel og leveranse

Planlagt utvikling avbrytes ofte av manuell kontooppretting. KI lager en samlet oversikt over avbruddstyper, tidsestimat og saker som mangler en tydelig eier.

## Kontroll

Teamet validerer kategorier og representativitet; individuelle meldinger eller aktivitetsspor skal ikke brukes som skjult tidsregistrering.

## Mål effekt

Mål kartleggingstid og andel synliggjort arbeid, sammen med teamopplevelse, feilkategorisering og kostnad ved registrering.
