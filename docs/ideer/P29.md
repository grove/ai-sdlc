# P29 Avdekke motstridende dokumentasjon og regler

<a id="p29"></a>

- **Steg:** [Problem](../steg/problem.md)
- **Temaområde:** [Kostnader risiko og prioritering](../steg/problem.md#p-kategori-4)
- **Arbeidsform:** Rådgivning
- **Særlig relevant for:** Dokumenter og beslutninger, Regulert arbeid, Forvaltning, Eldre systemer

## Muligheten

KI kan sammenligne godkjente dokumenter, systembeskrivelser og driftsrutiner for å finne påstander som motsier hverandre. Den kan knytte motsetningene til praktiske konsekvenser, slik at dokumentasjon behandles som et reelt kvalitetsproblem og ikke bare et spørsmål om mer tekst.

## Grunnlag

Versjonerte dokumenter, kildeeiere, gyldighetsdatoer, regelbeskrivelser og eksempler på arbeid som avhenger av at informasjonen er korrekt.

## Forutsetninger

Kjente dokumenteiere, versjonsmetadata og en fast prosess for å avklare autoritative kilder ved konflikt.

## Eksempel og leveranse

Utviklerguiden og driftsrutinen angir ulike tidsgrenser for sletting. KI leverer en konfliktliste med ordrette utdrag, kildeversjoner og roller som må avklare reglene.

## Kontroll

Ansvarlig fageier avgjør hvilken kilde som gjelder; KI må vise motstriden og ikke automatisk harmonisere uklare regler.

## Mål effekt

Mål tid til bekreftet dokumentkonflikt, sammen med feilaktige funn og senere arbeid utført etter utdaterte regler.
