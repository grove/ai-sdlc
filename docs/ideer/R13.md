# R13 Koordiner publisering av grensesnitt og konsumentovergang

<a id="r13"></a>

- **Steg:** [Produksjon](../steg/produksjon.md)
- **Temaområde:** [Utrulling og aktivering](../steg/produksjon.md#r-kategori-2)
- **Arbeidsform:** Utforming
- **Særlig relevant for:** Integrasjon, Plattform, Produktutvikling

## Muligheten

KI kan lage en konkret aktiveringsplan for nye API eller hendelsesversjoner og følge opp nødvendige bekreftelser fra konsumenteiere. Den skiller tilgjengeliggjøring fra avvikling av tidligere grensesnitt. Dette gjør leveransen lettere å koordinere når andre team eller eksterne partnere må endre egne løsninger.

## Grunnlag

Publiseringsplan, godkjente kontrakter, konsumentregister, avviklingsfrister, overgangsveiledning og avtalte kontakt og godkjenningsprosesser for integrasjonspartnere.

## Forutsetninger

Konsumentene må kunne identifiseres rimelig godt, og kontraktene må angi hvordan nye versjoner publiseres og gamle fases ut.

## Eksempel og leveranse

Et nytt ordre API får en publiseringspakke med versjonsendepunkt, migreringsveiledning og konsumentoversikt som viser hvem som har bekreftet klargjøring for overgangen.

## Kontroll

Integrasjonseier godkjenner publisering og kommunikasjon. Ingen gammel versjon fjernes uten avtalte vilkår, og automatiske meldinger krever eksplisitt utsendelsesmandat.

## Mål effekt

Tid til avtalt konsumentovergang, sammen med klienter som brytes, ubesvarte overgangsavklaringer og forlengelser av tidligere grensesnitts levetid.
