# V32 Vurder om testmiljøet representerer målmiljøet

<a id="v32"></a>

- **Steg:** [Verifisering](../steg/verifisering.md)
- **Temaområde:** [Verifikasjonsprosess og bevis](../steg/verifisering.md#v-kategori-4)
- **Arbeidsform:** Rådgivning
- **Særlig relevant for:** Plattform, Embedded og OT, Regulert arbeid

## Muligheten

KI kan sammenligne miljøbeskrivelser, konfigurasjon og testdata med den planlagte produksjonsflaten. Den identifiserer forskjeller som kan gjøre testresultater lite representative, eksempelvis manglende nettverksgrenser eller for små datamengder. Dette hjelper teamet med å beskrive hvor langt verifikasjonsbevisene faktisk kan generaliseres før godkjenning.

## Grunnlag

Test- og produksjonsprofiler uten hemmeligheter, avhengighetsversjoner, datastruktur, kapasitet, nettverksregler og kjente miljøavvik.

## Forutsetninger

Miljøkonfigurasjon og avhengigheter må kunne sammenlignes, og teamet må ha en eksplisitt beskrivelse av målmiljøets viktigste egenskaper.

## Eksempel og leveranse

Før en migrering lager KI en forskjellsrapport som viser at testmiljøet mangler produksjonens proxy og sertifikatkjede, med forslag til nødvendige tilleggstester.

## Kontroll

Plattform- og testansvarlig vurderer avvikenes betydning. Representative forhold skal etableres trygt uten å kopiere sensitive produksjonsdata ukritisk til test.

## Mål effekt

Tid til identifiserte miljøgap, sammen med feil som bare oppstår i målmiljøet og andel kritiske forutsetninger som faktisk testes.

## Bruk ideen i prosjektet

Avtal hva som er et korrekt resultat og hvilke uavhengige bevis godkjenningen krever. Mål kontrollarbeidet sammen med feil som oppdages, feil som overses og unødvendige avslag.
