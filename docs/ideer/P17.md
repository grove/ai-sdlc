# P17 Identifisere kostbare områder i eldre kode

<a id="p17"></a>

- **Steg:** [Problem](../steg/problem.md)
- **Temaområde:** [Teknologi data og drift](../steg/problem.md#p-kategori-3)
- **Arbeidsform:** Rådgivning
- **Særlig relevant for:** Eldre systemer, Forvaltning, Produktutvikling

## Muligheten

KI kan kombinere endringshistorikk, feilrapporter og arkitekturinformasjon for å peke ut kodeområder som er krevende å vedlikeholde. Den kan formulere avgrensede problemer, som uklare grenser eller sterk kobling, fremfor å anbefale omfattende omskriving ut fra kompleksitet alene.

## Grunnlag

Repo, endringshistorikk, feil- og supportdata, systemkart og representative beskrivelser av faktisk arbeid i kodeområdene.

## Forutsetninger

Godkjent repotilgang, sporbar historikk og tilgang til utviklere med erfaring fra de aktuelle modulene.

## Eksempel og leveranse

Små endringer i prisregler berører mange moduler og tester. KI leverer et hotspotnotat med endringsmønstre, dokumenterte feil og kandidater til videre analyse.

## Kontroll

Kodeeier validerer funn og forretningskritikalitet; høy kompleksitet eller mange commits er ikke alene grunnlag for modernisering.

## Mål effekt

Mål analysetid og bekreftede vedlikeholdsproblemer, sammen med endringskostnad, regresjoner og unødvendige moderniseringsforslag fra analysen.
