# A06 Implementere avgrensede mobilfunksjoner

<a id="a06"></a>

- **Steg:** [Agentutførelse](../steg/agentutforelse.md)
- **Temaområde:** [Produkt og brukerflater](../steg/agentutforelse.md#a-kategori-1)
- **Arbeidsform:** Avgrenset utførelse
- **Særlig relevant for:** Mobil og klient, Produktutvikling, Integrasjon

## Muligheten

En agent kan bygge avgrensede mobilfunksjoner som lokal lagring, varsling og håndtering av nettverksbrudd. Den kan bruke prosjektets plattformmønstre og levere konkrete tilstander, slik at vanlig plattformarbeid går raskere uten at særkravene til klienten forsvinner.

## Grunnlag

Plattformversjoner, apparkitektur, tillatelsesregler, synkroniseringskontrakter og godkjente brukerflyter.

## Forutsetninger

Tilgang til representative testmiljøer og klare regler for hvilke data som kan lagres på enheten.

## Eksempel og leveranse

En feltapp får lagring av utkast uten nett og tydelig synkroniseringsstatus; leveransen inkluderer kode og simulering av brudd og konflikt.

## Kontroll

Mobilutvikler kontrollerer livssyklus og datasikkerhet; resultatet prøves på relevante enheter og kan ikke godkjennes bare i simulator.

## Mål effekt

Tid til godkjent mobilfunksjon, sammen med datatap, klientfeil, batteribruk og problemer ved nettverksbytte.

## Bruk ideen i prosjektet

Avtal leveranse, verktøy, filområder, stoppsignaler og ansvar for gjennomgang. Ta med oppsett, menneskelig oppfølging og senere feilretting når forsøket vurderes.
