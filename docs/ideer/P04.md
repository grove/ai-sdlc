# P04 Avdekke problemer med tilgjengelighet

<a id="p04"></a>

- **Steg:** [Problem](../steg/problem.md)
- **Temaområde:** [Brukerbehov og virksomhetsproblemer](../steg/problem.md#p-kategori-1)
- **Arbeidsform:** Rådgivning
- **Særlig relevant for:** Produktutvikling, Mobil og klient, Dokumenter og beslutninger, Regulert arbeid

## Muligheten

KI kan strukturere rapporterte barrierer fra brukertester, tilgjengelighetsgjennomganger og support. Den kan koble barrierene til konkrete brukeroppgaver og prioriteringsbehov, slik at tilgjengelighet blir forstått som problemer brukere møter, før tekniske rettinger planlegges og verifiseres.

## Grunnlag

Tilgjengelighetsfunn, brukeroppgaver, testnotater, støttede hjelpemidler og beskrivelser av aktuelle grensesnitt eller dokumenter.

## Forutsetninger

Tilgang til representative testfunn, kompetanse på universell utforming og avklart målgruppe for løsningen.

## Eksempel og leveranse

Rapporter om tastaturbruk samles til problemet «bestillingen kan ikke fullføres uten mus». Leveransen beskriver berørte steg, kilder og behov for videre undersøkelser.

## Kontroll

Tilgjengelighetsfaglig ansvarlig bekrefter konsekvensen med faktiske hjelpemidler og relevante brukere; KI erstatter ikke slik testing.

## Mål effekt

Mål tid fra barriererapport til prioritert problem, sammen med bekreftede og oversette kritiske barrierer.
