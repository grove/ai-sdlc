# A20 Lage analyser og rapportgrunnlag

<a id="a20"></a>

- **Steg:** [Agentutførelse](../steg/agentutforelse.md)
- **Temaområde:** [Data integrasjoner og testartefakter](../steg/agentutforelse.md#a-kategori-3)
- **Arbeidsform:** Avgrenset utførelse
- **Særlig relevant for:** Data og analyse, Produktutvikling, Dokumenter og beslutninger

## Muligheten

KI kan omforme godkjente metrikkdefinisjoner til spørringer, semantiske modeller og rapportutkast. Den kan forklare tabellkoblinger, filtrering og aggregering, slik at fagpersoner lettere ser hva tallene betyr og kan kontrollere datagrunnlaget før rapporten brukes.

## Grunnlag

Metrikkatalog, datamodell, datakvalitetsinformasjon, tilgangsregler og kjent rapporteringsbehov.

## Forutsetninger

Godkjente metrikkdefinisjoner og en fagperson som kan kontrollere både data og tolkning.

## Eksempel og leveranse

En rapport over behandlingstid bygges med tydelig start og slutt, utelukkelsesregler og gruppering; leveransen inkluderer SQL, definisjoner og avstemmingsutdrag.

## Kontroll

Analytiker kontrollerer teller, nevner og datamodell; spørringer kjøres lesende med ressursgrenser, og illustrasjonstall merkes.

## Mål effekt

Tid til godkjent analysegrunnlag, balansert med feil i nøkkeltall, ufullstendige data og ressursbruk.

## Bruk ideen i prosjektet

Avtal leveranse, verktøy, filområder, stoppsignaler og ansvar for gjennomgang. Ta med oppsett, menneskelig oppfølging og senere feilretting når forsøket vurderes.
