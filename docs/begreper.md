# Begreper

| **Begrep** | **Betydning** |
| --- | --- |
| SDLC | Systemutviklingslivssyklusen, fra behov og analyse til utvikling, bruk, drift og avvikling. |
| Agent | KI-system som kan planlegge og bruke verktøy innen et gitt mandat. Mennesker beholder beslutningsansvar. |
| Baseline | Målt utgangspunkt med kjent periode, oppgavetype, definisjon og datakvalitet. |
| Kontrollmål | Balanserende mål for kvalitet, sikkerhet, kostnad eller mennesker. Kalles også guardrail. |
| Testorakel | Et pålitelig grunnlag for å avgjøre forventet riktig resultat, for eksempel godkjent regel, fasit eller uavhengig beregning. |
| ADR | Arkitekturbeslutning med begrunnelse, alternativer og konsekvenser. |
| PR og diff | Forslag til innlemming av endringer og den konkrete forskjellen fra tidligere versjon. |
| CI og CD | Automatiske bygge- og kontrollprosesser, samt kontrollert levering eller utrulling. |
| API og kontrakttest | Grensesnitt mellom systemer og test av avtalte forventninger mellom produsent og konsument. |
| SAST og DAST | Statisk sikkerhetsanalyse av kode og dynamisk sikkerhetsanalyse av en kjørende løsning i autorisert testmiljø. |
| SCA og SBOM | Analyse av programvareavhengigheter og oversikt over komponenter i leveransen. |
| Fuzzing og mutasjonstest | Systematisk variasjon av testinput og bevisst endring av kode for å undersøke testenes evne til å avdekke feil. |
| SLO og SLI | Avtalt mål for tjenestens kvalitet og indikatoren som måler den. Feilbudsjett uttrykker tillatt avvik fra målet i perioden. |
| Canary og funksjonsflagg | Gradvis eksponering for en begrenset gruppe og mekanismer som styrer aktivering av funksjonalitet. |
| p85 og p95 | Persentiler som viser verdien henholdsvis 85 og 95 prosent av observasjonene ligger på eller under. |
| RAG og embedding | Gjenfinning som gir modellen kildekontekst, og numeriske representasjoner som kan støtte søk og gruppering. |
| Idempotens | At gjentatt behandling av samme operasjon ikke gir uønskede ekstra virkninger. |
| Oppgaveenhet | Avgrenset arbeid med forhåndsdefinert aksept. Sammenlign enheter med rimelig likt innhold og kompleksitet. |
| Total eierkostnad | Samlet relevant kostnad til oppsett, bruk, kontroll, støtte og vedlikehold i valgt periode. |
| Avståelse og eskalering | At agenten stopper eller innhenter avklaring når grunnlaget eller mandatet ikke er tilstrekkelig. |
