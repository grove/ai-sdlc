# Agent execution

Turn approved assignments into concrete, traceable delivery proposals within clear technical and organizational boundaries. Implementation includes code, configuration, data, tests, documentation and other professional artifacts.

**The question in this step:** What work can be carried out within the mandate?

**Typical delivery:** An evaluable artefact or bounded result with diff, driving proof and uncertainty.

## Place in the learning loop

The execution follows the assignment's mandate and produces an assessable result. Describe changes, runs and uncertainty, so that the next step can verify both the artifact and that the work stayed within the boundaries.

Previous step is [Context](context.md). The next step is [Verification](verification.md). The loop is repeated when the experience provides the supporting evidence for a new improvement.
