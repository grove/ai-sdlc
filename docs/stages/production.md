# Production

Make a verified delivery available for agreed use with controlled activation, operational readiness and clear reception. Production can be a running service, distributed package, a computer product, or an approved decision that is actually put into use. AI supports coordination and implementation within an explicit mandate.

**The question in this step:** Can the delivery be put into use under control?

**Typical delivery:** Correctly approved version in intended use, with owner, observation and plan for errors.

## Place in the learning loop

Production includes intended use even without a running service: a published package, a computer product, a certified delivery or an approved decision that the recipient actually uses. Set local definition before work starts.

Previous step is [Verification](verification.md). The next step is [Observation](observation.md). The loop is repeated when the experience provides the supporting evidence for a new improvement.
