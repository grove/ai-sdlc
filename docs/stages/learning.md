# Learning

Turn observed results into better decisions, working methods, knowledge and controls. Proposals from AI are introduced as versioned changes that must be tested and measured themselves.

**The question in this step:** What should the team change next?

**Typical delivery:** A decided change in working methods, knowledge or control with the owner and follow-up.

## Place in the learning loop

Learning has been completed when the experience affects a concrete decision or working mechanism and the effect can be followed up. Changes to instructions, tools and control rules are versioned and assessed before use.

Previous step is [Observation](observation.md). The next step is [Problem](problem.md). The loop is repeated when the experience provides the supporting evidence for a new improvement.
