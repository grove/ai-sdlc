# Context

Give people and agents relevant, authorized and verifiable knowledge before they perform a task. The ideas include both system understanding and management of the knowledge base itself.

**The question in this step:** Do the human and the agent have a sufficiently correct basis?

**Typical delivery:** A limited and versioned context with sources, requirements, access and open questions.

## Place in the learning loop

Context must give the thesis the right basis and make deficiencies visible. Source content cannot give the agent new powers, and a large context package is not in itself proof of foundation adequacy.

Previous step is [Hypothesis](hypothesis.md). The next step is [Agent execution](agent-execution.md). The loop is repeated when the experience provides the supporting evidence for a new improvement.
