# Problem

Find and narrow down problems that are valuable to solve, with visible sources and a measurable starting point.

**The question in this step:** Which problem is worth solving?

**Typical delivery:** A problem card with target group, actual observation, consequence, delimitation and owner.

## Place in the learning loop

Problem uses existing experiences to find the next challenge. Separate observed patterns from possible causes, and allow affected users and responsible owners to confirm the significance of the problem.

Previous step is [Learning](learning.md). The next step is [Hypothesis](hypothesis.md). The loop is repeated when the experience provides the supporting evidence for a new improvement.
