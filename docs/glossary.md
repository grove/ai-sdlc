# Glossary

| Term | Meaning |
| --- | --- |
| **SDLC** | Software development life cycle: planning, building, verifying, releasing, operating, improving, and retiring software. |
| **AI agent** | A system that can plan and use tools within an explicitly authorized scope. People remain accountable for approval and outcomes. |
| **Baseline** | A measured starting point with a defined observation period, task type, measurement method, and data quality. |
| **Guardrail metric** | A balancing measure for quality, security, costs, or human burden that must not deteriorate when a primary metric improves. |
| **Test oracle** | A reliable reference for expected results, such as an approved business rule, specification, or independent calculation. |
| **ADR** | Architecture decision record documenting a choice, rationale, alternatives, and consequences. |
| **PR / diff** | Pull request proposing changes and the comparison showing those changes. |
| **CI / CD** | Continuous integration and continuous delivery or deployment, using automated build, test, and release processes. |
| **API / contract test** | Application programming interface and a test of agreed behavior between provider and consumer. |
| **SAST / DAST** | Static application security testing and dynamic application security testing in an authorized environment. |
| **SCA / SBOM** | Software composition analysis and a software bill of materials documenting dependencies. |
| **Fuzzing / mutation testing** | Automated variation of inputs and deliberate changes to code to evaluate how well tests find defects. |
| **SLO / SLI** | Service-level objective and service-level indicator; an error budget defines acceptable deviation in a period. |
| **Canary release / feature flag** | Gradual exposure to a small audience and a mechanism for activating or disabling functionality. |
| **p85 / p95** | The 85th and 95th percentiles of an observed distribution, respectively. |
| **RAG / embeddings** | Retrieval-augmented generation, which provides source context to a model, and numerical representations used for search or grouping. |
| **Idempotency** | Repeating an operation does not cause additional unintended effects. |
| **Task unit** | Bounded work with predefined acceptance criteria; compare tasks with reasonably similar scope and complexity. |
| **TCO** | Total cost of ownership, including setup, use, review, support, and maintenance over a defined period. |
| **Escalation / safe stop** | Requiring clarification or stopping an agent when evidence, authorization, or safeguards are insufficient. |
