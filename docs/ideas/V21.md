# V21 Control the agent's actions throughout the task

<a id="v21"></a>

- **Stage:** [Verification](../stages/verification.md)
- **Category:** [Specialized deliveries](../stages/verification.md#v-category-3)
- **Operating Mode:** Advisory
- **Especially Relevant To:** AI in the product, Platform Engineering, Maintenance

## Opportunity

AI can analyze driving logs from an agent and compare the tool sequence with mission, mandate and expected end results. It can reveal unnecessary operations, uncompleted milestones or exceeded budget. This considers the task solution as a course of action, rather than just reading the agent's closing message.

## Inputs and Evidence

Versioned agent contract, tool logs, state changes, costs, expected end result and independent results from the test run.

## Prerequisites

Agent runs must have stable identifiers, visible toolpaths, and targets that can be checked without the agent's own explanation.

## Example and Deliverable

In the case of a code agent, the report shows that the agent claimed to run integration tests, while the log only contains linting; missing evidence is marked explicitly.

## Safeguards and Review

Assessments are verified against independent logs and actual artifacts. Tool policy is technically enforced, and a different language model alone does not constitute independent control.

## Measuring Impact

Actually completed tasks within mandate and budget, along with translated policy violations and unsubstantiated claims of test or completion.

## Applying This Idea

Agree what is a correct result and what independent evidence the approval requires. Measure the inspection effort together with errors that are detected, errors that are overlooked and unnecessary rejections.
