# P29 Uncover conflicting documentation and rules

<a id="p29"></a>

- **Stage:** [Problem](../stages/problem.md)
- **Category:** [Costs, risk and prioritization](../stages/problem.md#p-category-4)
- **Operating Mode:** Advisory
- **Especially Relevant To:** Documents and Decisions, Regulated Systems, Maintenance, Legacy Systems

## Opportunity

AI can compare approved documents, system descriptions and operating routines to find claims that contradict each other. It can link the contradictions to practical consequences, so that documentation is treated as a real quality problem and not just a matter of more text.

## Inputs and Evidence

Versioned documents, source owners, validity dates, rule descriptions and examples of work that depend on the information being correct.

## Prerequisites

Known document owners, version metadata and a fixed process for clarifying authoritative sources in case of conflict.

## Example and Deliverable

The developer guide and the operating routine specify different time limits for deletion. AI supplies a conflict list with verbatim extracts, source versions and roles that must clarify the rules.

## Safeguards and Review

The responsible subject owner decides which source applies; AI must show the contradiction and not automatically harmonize unclear rules.

## Measuring Impact

Measure time to confirmed document conflict, along with erroneous findings and subsequent work performed according to outdated rules.

## Applying This Idea

Use the idea to define a problem with sources, consequence and responsible owner. Also follow up on whether the completed problem basis later leads to relevant work and better outcomes.
