# A29 Write documentation that accompanies the delivery

<a id="a29"></a>

- **Stage:** [Agent Execution](../stages/agent-execution.md)
- **Category:** [Platform and other deliveries](../stages/agent-execution.md#a-category-4)
- **Operating Mode:** Drafting
- **Especially Relevant To:** Documents and Decisions, Integrations, Product Development

## Opportunity

AI can update user help, developer guides and API samples from a verifiable change and approved sources. It can produce targeted documentation at the same time as the work, so that documentation debt and questions from recipients do not grow after delivery.

## Inputs and Evidence

Changes diff, contracts, approved terms, documentation template and information about the target group.

## Prerequisites

Sources that describe the specific version and owners that can approve content for the target audience.

## Example and Deliverable

A new API gets updated examples and explanation of error responses; the agent delivers documentation changes that can be tested against the same build as the implementation.

## Safeguards and Review

Subject owner checks correctness and tries critical examples; claims about features and support must be supported by actual implementation.

## Measuring Impact

Time to approved documentation, balanced with errors in examples and later support needs of users or developers.

## Applying This Idea

Define the deliverable, tools, file areas, stop signals and responsibility for review. Include setup, human follow-up and later error correction when the experiment is evaluated.
