# A12 Translate code into new technology

<a id="a12"></a>

- **Stage:** [Agent Execution](../stages/agent-execution.md)
- **Category:** [Maintenance and modernization](../stages/agent-execution.md#a-category-2)
- **Operating Mode:** Bounded Execution
- **Especially Relevant To:** Legacy Systems, Platform Engineering, Embedded and OT

## Opportunity

AI can assist in moving delimited modules between languages, runtimes or frameworks. It can preserve explicit contracts and point out semantic differences, so that modernization is divided into controllable steps rather than an unmanageable total rewrite.

## Inputs and Evidence

Original code, target technology, contracts, representative inputs and outputs and technical limitations.

## Prerequisites

A limited contract and reference basis that makes the old and new solution comparable.

## Example and Deliverable

A batch job is moved to a new language; the agent delivers a module with the same interface and an overview of differences in date and number processing.

## Safeguards and Review

Technical owner assesses semantic compliance; automatic translation must be checked with independent examples and relevant performance requirements.

## Measuring Impact

Time per approved migrated module, balanced with behavior deviations, operating cost and maintenance needs.

## Applying This Idea

Define the deliverable, tools, file areas, stop signals and responsibility for review. Include setup, human follow-up and later error correction when the experiment is evaluated.
