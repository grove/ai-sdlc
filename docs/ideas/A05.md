# A05 Create and maintain language variants

<a id="a05"></a>

- **Stage:** [Agent Execution](../stages/agent-execution.md)
- **Category:** [Product and user interfaces](../stages/agent-execution.md#a-category-1)
- **Operating Mode:** Drafting
- **Especially Relevant To:** Product Development, Mobile and Client Software, Documents and Decisions

## Opportunity

AI can prepare translations, help texts and messages in an existing language framework. It can follow terminology and style, handle variables and suggest where text needs to be reformulated to work in different languages ​​and screen sizes.

## Inputs and Evidence

Approved original text, list of terms, language files, space limitations and rules for variables and inflection.

## Prerequisites

An established scheme for localization and identifiable owners for linguistic and professional quality.

## Example and Deliverable

An app gets suggestions for new language files and updated error messages; the delivery marks technical expressions and texts that require checking by a person with language skills.

## Safeguards and Review

Language and subject owner approves critical content; automatic checks verify variables, character encoding and missing keys.

## Measuring Impact

Time to approved language version, balanced with meaning errors, errors in variables and reported comprehension problems.

## Applying This Idea

Define the deliverable, tools, file areas, stop signals and responsibility for review. Include setup, human follow-up and later error correction when the experiment is evaluated.
