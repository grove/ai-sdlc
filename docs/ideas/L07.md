# L07 Adjust the measurement system according to known blind spots

<a id="l07"></a>

- **Stage:** [Learning](../stages/learning.md)
- **Category:** [Improve hypotheses and prioritization](../stages/learning.md#l-category-1)
- **Operating Mode:** Drafting
- **Especially Relevant To:** Data and Analytics, Platform Engineering, Regulated Systems

## Opportunity

AI can use data gaps and analysis disputes from an attempt to propose better event definitions, effort tests and links between systems. The changes make the next experiment more verifiable, while allowing the team to remove measurements that do not help any decision.

## Inputs and Evidence

Data quality findings, missing analyses, metric definitions and experiences from decision-making meetings.

## Prerequisites

Ownership of instrumentation and a concrete decision every new measurement must support.

## Example and Deliverable

A team lacks time spent on discarded proposals. AI prepares a change in the log form and measurement catalog with data minimization and a migration plan.

## Safeguards and Review

Data owner approves definition changes and versions them. Do not compare new measurements with old baseline without clear break marking.

## Measuring Impact

Proportion of decisions with sufficient supporting data, with collection cost and unnecessary personal data as control measures.

## Applying This Idea

Turn the learning into a concrete measure with owner and follow-up date. Keep negative findings and test the change before using it as a new standard or scaling it to more tasks.
