# O20 Discover changed resource use and operating costs

<a id="o20"></a>

- **Stage:** [Observation](../stages/observation.md)
- **Category:** [Operational quality and risk](../stages/observation.md#o-category-3)
- **Operating Mode:** Advisory
- **Especially Relevant To:** Platform Engineering, Data and Analytics, AI in the product

## Opportunity

AI can compare cloud bills, resource measurements and load to investigate whether a change increases costs per useful transaction. It can also point to energy-intensive work when reliable energy data exists, and distinguish measured values ​​from rough estimates.

## Inputs and Evidence

Billing data, resource consumption, traffic volume, versions and any documented energy measurements.

## Prerequisites

Link between cost data, load and the change in question.

## Example and Deliverable

An AI-made data transformation uses more processor resources. AI delivers a cost analysis per correctly processed data set and proposals for further profiling.

## Safeguards and Review

Platform and finance control unit costs. Do not report emissions or energy gains without a documented data base and system limit.

## Measuring Impact

Operating cost per correct transaction or data set, with response time, error rate and comparable load.

## Applying This Idea

Link the measurement to the agreed hypothesis and actual exposure to the measure. Show data gaps, alternative explanations and uncertainty before an observed change is referred to as an effect.
