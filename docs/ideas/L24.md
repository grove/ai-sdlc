# L24 Replace stable AI work with simpler automation

<a id="l24"></a>

- **Stage:** [Learning](../stages/learning.md)
- **Category:** [Improve agents and work tools](../stages/learning.md#l-category-3)
- **Operating Mode:** Drafting
- **Especially Relevant To:** Platform Engineering, Maintenance, Packaged Software

## Opportunity

AI can find repetitive tasks that, after learning, have become sufficiently well-defined for scripts, rules or templates. It can propose a simpler implementation that reduces model cost and variation, while AI is still used where interpretation or uncertainty requires it.

## Inputs and Evidence

Repetitive task patterns, stable decision rules, deviations, costs and existing automation options.

## Prerequisites

A stable pattern with clarified rules and sufficient tests for boundary conditions.

## Example and Deliverable

An agent changes the same configuration field each time. AI suggests a validated script with parameter control and a test set for deviations.

## Safeguards and Review

The technical owner verifies the scope of the rules. Keep explicit stop for cases that the script does not cover.

## Measuring Impact

Cost and variation per correctly performed task, with maintenance effort and errors outside of normal cases.

## Applying This Idea

Turn the learning into a concrete measure with owner and follow-up date. Keep negative findings and test the change before using it as a new standard or scaling it to more tasks.
