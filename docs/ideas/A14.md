# A14 Carry out targeted performance improvement

<a id="a14"></a>

- **Stage:** [Agent Execution](../stages/agent-execution.md)
- **Category:** [Maintenance and modernization](../stages/agent-execution.md#a-category-2)
- **Operating Mode:** Bounded Execution
- **Especially Relevant To:** Data and Analytics, Platform Engineering, Product Development

## Opportunity

AI can use profiling and known bottlenecks to suggest specific changes to algorithms, queries or resource use. It can produce bounded alternatives that are measured under the same conditions, allowing the team to improve observed problems rather than theoretical weaknesses.

## Inputs and Evidence

Profiling data, load pattern, measurement setup, current code and requirements for correctness and resource use.

## Prerequisites

A reproducible measurement of the bottleneck and a safe test environment with a representative load.

## Example and Deliverable

A slow report gets a suggested query change and index; the delivery includes a benchmark recipe and risk of changed writing cost.

## Safeguards and Review

Developer and data controller check result equality and production relevance; synthetic benchmark alone does not determine the value.

## Measuring Impact

Relevant response time or resource cost, balanced with correctness, write performance and increased maintenance complexity.

## Applying This Idea

Define the deliverable, tools, file areas, stop signals and responsibility for review. Include setup, human follow-up and later error correction when the experiment is evaluated.
