# A01 Implement a limited product function

<a id="a01"></a>

- **Stage:** [Agent Execution](../stages/agent-execution.md)
- **Category:** [Product and user interfaces](../stages/agent-execution.md#a-category-1)
- **Operating Mode:** Bounded Execution
- **Especially Relevant To:** Product Development, Integrations, Legacy Systems

## Opportunity

An agent can implement a coherent, small function from approved requirements to code, relevant tests and documentation. It can follow existing patterns and deliver a measurable change, so that the developer spends more time on professional selection and control.

## Inputs and Evidence

Clarified user history, contracts, code base, approved patterns, test basis and explicit acceptance criteria.

## Prerequisites

Limited change area, working test environment and an agent who can only write in an authorized workspace.

## Example and Deliverable

For an order overview, the agent implements filtering in the API and interface and delivers a PR with diff, tests run and known constraints.

## Safeguards and Review

Developer reviews design and code; independent CI confirms test results before the change is allowed to proceed towards production.

## Measuring Impact

Total time to approved function, including review and correction, balanced with errors after delivery.

## Applying This Idea

Define the deliverable, tools, file areas, stop signals and responsibility for review. Include setup, human follow-up and later error correction when the experiment is evaluated.
