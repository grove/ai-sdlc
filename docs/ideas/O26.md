# O26 Ensure the correct link between measures and exposure

<a id="o26"></a>

- **Stage:** [Observation](../stages/observation.md)
- **Category:** [Credible impact analysis](../stages/observation.md#o-category-4)
- **Operating Mode:** Advisory
- **Especially Relevant To:** Product Development, AI in the product, Platform Engineering

## Opportunity

AI can help reconstruct which tasks, teams or users actually encountered a measure, and when. The analysis separates installed tools from active treatment and registers overlap between experiments, so that the comparison uses the correct exposure basis.

## Inputs and Evidence

Experiment registry, agent runs, feature flag logs, release events and relevant cohort definitions.

## Prerequisites

Clearly defined measures and events that show actual use or exposure.

## Example and Deliverable

A license is assigned to the entire team, but only some task types use the agent. AI creates an exposure matrix at task level.

## Safeguards and Review

The analysis manager approves the processing definition. Keep the chosen analysis design and avoid picking only good agent trials afterwards.

## Measuring Impact

Proportion of observations with correct treatment status, with unclear exposure and contamination between groups.

## Applying This Idea

Link the measurement to the agreed hypothesis and actual exposure to the measure. Show data gaps, alternative explanations and uncertainty before an observed change is referred to as an effect.
