# L18 Improve retrieval of relevant context

<a id="l18"></a>

- **Stage:** [Learning](../stages/learning.md)
- **Category:** [Improve agents and work tools](../stages/learning.md#l-category-3)
- **Operating Mode:** Drafting
- **Especially Relevant To:** AI in the product, Documents and Decisions, Legacy Systems

## Opportunity

AI can analyze which tasks received irrelevant, missing or outdated sources, and suggest better source selection, document sharing and search phrases. The proposals are evaluated on specific questions, so that more context is not automatically confused with more correct context.

## Inputs and Evidence

Questions and source selection from approved runs, source summary, access rules and error reports.

## Prerequisites

A controlled collection of questions with known relevant sources and source versions.

## Example and Deliverable

An agent is fetching the wrong API version. AI proposes version filtering and creates evaluation questions that require the right source and clear revision.

## Safeguards and Review

Context owner actually controls source hit and access. Improved retrieval must not extend access to other projects' information.

## Measuring Impact

Proportion of tasks with correct relevant source, with unfair hits, token cost and response benefit.

## Applying This Idea

Turn the learning into a concrete measure with owner and follow-up date. Keep negative findings and test the change before using it as a new standard or scaling it to more tasks.
