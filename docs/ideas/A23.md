# A23 Construct tests from approved expectations

<a id="a23"></a>

- **Stage:** [Agent Execution](../stages/agent-execution.md)
- **Category:** [Data integrations and test artifacts](../stages/agent-execution.md#a-category-3)
- **Operating Mode:** Bounded Execution
- **Especially Relevant To:** Product Development, Legacy Systems, Regulated Systems

## Opportunity

AI can write test code based on requirements, contracts and confirmed examples, and make it executable in existing frameworks. The task is to produce test artifacts; whether the tests actually reveal relevant errors must be assessed in the separate verification step.

## Inputs and Evidence

Requirements, approved reference responses, test frameworks, contracts and desired positive and negative scenarios.

## Prerequisites

A verifiable basis for expectations and a process that assesses the usefulness of the tests regardless of the implementation.

## Example and Deliverable

For an access rule, the agent creates tests for allowed and denied access, with explicit expectations from the requirements list and links to each criterion.

## Safeguards and Review

Tests are reviewed against independent expectations; the agent may not change acceptance requirements or existing failure tests to obtain green status.

## Measuring Impact

Time to approved test set, balanced with error detection, maintenance work and number of misleading or unstable tests.

## Applying This Idea

Define the deliverable, tools, file areas, stop signals and responsibility for review. Include setup, human follow-up and later error correction when the experiment is evaluated.
