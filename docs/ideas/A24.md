# A24 Create synthetic test data and simulators

<a id="a24"></a>

- **Stage:** [Agent Execution](../stages/agent-execution.md)
- **Category:** [Data integrations and test artifacts](../stages/agent-execution.md#a-category-3)
- **Operating Mode:** Drafting
- **Especially Relevant To:** Integrations, Data and Analytics, Embedded and OT

## Opportunity

AI can produce proposals for synthetic data, stubs and simulators that make development possible without continuous access to real external systems. It can vary scenarios according to explicit rules and document what the simulation covers and does not cover.

## Inputs and Evidence

Data schema, business rules, contracts, allowed examples and scenarios that the environment must support.

## Prerequisites

Known contracts and rules, approved data generation and a plan for later control against real system properties.

## Example and Deliverable

An integration gets a simulator that returns timeout, rate limitation and invalid responses, as well as a data set with clarified limit values and missing fields.

## Safeguards and Review

The supervisor validates realism and rules; synthetic data may have biases and should not inadvertently copy real people.

## Measuring Impact

Time spent waiting for test data or dependencies, balanced with bugs only discovered in real integration.

## Applying This Idea

Define the deliverable, tools, file areas, stop signals and responsibility for review. Include setup, human follow-up and later error correction when the experiment is evaluated.
