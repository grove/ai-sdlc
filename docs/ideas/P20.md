# P20 Uncover weak integrations and unclear ownership

<a id="p20"></a>

- **Stage:** [Problem](../stages/problem.md)
- **Category:** [Technology data and operation](../stages/problem.md#p-category-3)
- **Operating Mode:** Advisory
- **Especially Relevant To:** Integrations, Packaged Software, Legacy Systems, Data and Analytics

## Opportunity

AI can compare interface overviews, bug reports and ownership to find integrations that cause repeated interruptions or unclear responsibilities. It can separate contract problems, data problems and operational problems, so that projects prioritize the right area of ​​improvement before implementation starts.

## Inputs and Evidence

API and file contracts, integration maps, error history, change notifications and information about system and process owners in the value chain.

## Prerequisites

Updated integration overview, access to both sides and known source priority when contract documents are conflicting.

## Example and Deliverable

Nightly files fail with format changes, but the sender and recipient lack a common owner. AI creates an interface problem card with sources and clarification needs.

## Safeguards and Review

Both sides confirm contract, ownership and consequences; AI shall not derive responsibility only from old document names.

## Measuring Impact

Measure resolution time and confirmed integration issues, along with error repetition and unintended shifting of responsibilities between affected system owners.

## Applying This Idea

Use the idea to define a problem with sources, consequence and responsible owner. Also follow up on whether the completed problem basis later leads to relevant work and better outcomes.
