# O25 Check whether the measurement data is complete

<a id="o25"></a>

- **Stage:** [Observation](../stages/observation.md)
- **Category:** [Credible impact analysis](../stages/observation.md#o-category-4)
- **Operating Mode:** Advisory
- **Especially Relevant To:** Data and Analytics, Platform Engineering, Product Development

## Opportunity

AI can propose and run approved data checks for missing events, duplicates, biased selection and changed definitions. It delivers a data quality assessment prior to the impact analysis, so that the team does not declare improvement because failed tasks or late errors are missing from the data set.

## Inputs and Evidence

Measurement catalog, event extract, source systems' totals, data contracts and history of instrumentation changes.

## Prerequisites

Access to source totals and documented metrics with numerator, denominator and time window.

## Example and Deliverable

A dashboard shows a lower error rate after a release. AI finds missing client events and delivers a report that blocks the preliminary profit claim.

## Safeguards and Review

The data controller checks reconciliations in code or SQL. AI does not fill data gaps with fabricated observations.

## Measuring Impact

Proportion of measurements that pass data controls and time to corrected data breach, with remaining uncertainty.

## Applying This Idea

Link the measurement to the agreed hypothesis and actual exposure to the measure. Show data gaps, alternative explanations and uncertainty before an observed change is referred to as an effect.
