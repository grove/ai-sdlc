# K17 Putting together context for one specific task

<a id="k17"></a>

- **Stage:** [Context](../stages/context.md)
- **Category:** [Sources of data and work surface](../stages/context.md#k-category-3)
- **Operating Mode:** Drafting
- **Especially Relevant To:** Product Development, Legacy Systems, Documents and Decisions

## Opportunity

AI can select relevant extracts from code, requirements, decisions and operational information and collect them in a limited context package. The package reduces searching and unnecessary content, and provides the agent with sources that can be checked and updated as needed.

## Inputs and Evidence

Task description, approved source areas, search indexes, document status and rules for context size.

## Prerequisites

Task-specific access and sources that can be referenced with a stable identity or version.

## Example and Deliverable

For an invoice change, AI only supplies affected rules, code files and test examples, with source versions and a list of material that has been deliberately omitted.

## Safeguards and Review

Developer checks that critical requirements are included; relevance ranking is an aid and not proof of completeness.

## Measuring Impact

Time to clear context, along with rework from omissions and cost of unnecessary context.

## Applying This Idea

Agree which sources, access and quality requirements apply to the specific task. Measure both the time to usable context and rework due to deficiencies or errors in the foundation.
