# A20 Create analyzes and report basis

<a id="a20"></a>

- **Stage:** [Agent Execution](../stages/agent-execution.md)
- **Category:** [Data integrations and test artifacts](../stages/agent-execution.md#a-category-3)
- **Operating Mode:** Bounded Execution
- **Especially Relevant To:** Data and Analytics, Product Development, Documents and Decisions

## Opportunity

AI can transform approved metric definitions into queries, semantic models and draft reports. It can explain table links, filtering and aggregation, so that professionals can more easily see what the numbers mean and can check the data base before using the report.

## Inputs and Evidence

Metrics catalog, data model, data quality information, access rules and known reporting needs.

## Prerequisites

Approved metric definitions and a professional who can control both data and interpretation.

## Example and Deliverable

A report on processing time is built with a clear start and end, exclusion rules and grouping; the delivery includes SQL, definitions and reconciliation extracts.

## Safeguards and Review

Analyst checks numerator, denominator and data model; queries are run read-only with resource limits, and illustration figures are marked.

## Measuring Impact

Time to approved analysis basis, balanced with errors in key figures, incomplete data and resource use.

## Applying This Idea

Define the deliverable, tools, file areas, stop signals and responsibility for review. Include setup, human follow-up and later error correction when the experiment is evaluated.
