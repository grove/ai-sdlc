# H27 Compare options for safe data use

<a id="h27"></a>

- **Stage:** [Hypothesis](../stages/hypothesis.md)
- **Category:** [Risk and decision rules](../stages/hypothesis.md#h-category-4)
- **Operating Mode:** Advisory
- **Especially Relevant To:** Regulated Systems, Data and Analytics, AI in the product, Maintenance

## Opportunity

AI can structure solution options with different data flows, such as metadata, anonymized examples, synthetic data or approved local processing. It can highlight consequences for usefulness and measurability, so that the project examines solutions within clarified data and security requirements.

## Inputs and Evidence

Data classification, purpose of processing, approved services, requirements for representativeness and description of what information the agent task actually needs.

## Prerequisites

Updated data rules, clarified processing purposes and access to responsible persons who can control the actual data flows.

## Example and Deliverable

Support analysis contains personal data. AI creates an alternative note that compares metadata analysis, approved de-identification and processing in a clarified environment with associated limitations for the experiment.

## Safeguards and Review

The privacy and security officer determines permitted processing; AI cannot confirm anonymity, authorization or supplier terms on its own.

## Measuring Impact

Measure time to approved data alternative, together with analysis quality, data minimization and compliance with agreed processing limits in the pilot.

## Applying This Idea

Turn the idea into a limited experiment with hypothesis, basis for comparison and decision rules. Record the expected value, control needs and uncertainty before the results are available.
