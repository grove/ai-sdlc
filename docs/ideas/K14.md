# K14 Finding the right test basis and reference answers

<a id="k14"></a>

- **Stage:** [Context](../stages/context.md)
- **Category:** [Requirements and task understanding](../stages/context.md#k-category-2)
- **Operating Mode:** Drafting
- **Especially Relevant To:** Legacy Systems, Regulated Systems, Data and Analytics

## Opportunity

AI can retrieve existing tests, examples, and validated reference responses that describe expected behavior. It can also point out where the foundation is lacking, so that the execution does not create tests exclusively according to its own implementation or random assumptions.

## Inputs and Evidence

Approved test cases, requirements, contracts, characterization tests and available synthetic datasets.

## Prerequisites

Access to confirmed examples and a responsible person who can determine the expected behavior in case of doubt.

## Example and Deliverable

For a calculation engine, AI creates a test basis package with approved examples, limit values and cases where the subject owner must determine the correct answer before implementation.

## Safeguards and Review

Subject owner confirms reference response; the same agent's proposal must not automatically become both a conclusion and a control of one's own work.

## Measuring Impact

Time to usable test basis, together with errors in reference answers and lack of coverage of critical rules.

## Applying This Idea

Agree which sources, access and quality requirements apply to the specific task. Measure both the time to usable context and rework due to deficiencies or errors in the foundation.
