# A28 Automate repetitive developer tasks

<a id="a28"></a>

- **Stage:** [Agent Execution](../stages/agent-execution.md)
- **Category:** [Platform and other deliveries](../stages/agent-execution.md#a-category-4)
- **Operating Mode:** Bounded Execution
- **Especially Relevant To:** Legacy Systems, Platform Engineering, Maintenance

## Opportunity

AI can write small scripts and code rewrites for repetitive tasks such as name changes, file structure and updating default patterns. It can deliver a preview of the changes and make the automation reusable where the same work is otherwise done manually.

## Inputs and Evidence

Examples of desired transformation, delimited file areas, coding conventions and reversal needs.

## Prerequisites

A precise transformation pattern, version control and possibility of dry run before automatic change.

## Example and Deliverable

A new log function will be used in many modules; the agent creates a script that shows proposed changes and delivers a small sample for review.

## Safeguards and Review

Developer checks the transformation on representative cases; mass changes are limited and can be rolled back without overwriting other work.

## Measuring Impact

Time spent per approved transformation, together with unintended changes and effort for control and rollback.

## Applying This Idea

Define the deliverable, tools, file areas, stop signals and responsibility for review. Include setup, human follow-up and later error correction when the experiment is evaluated.
