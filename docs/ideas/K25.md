# K25 Keep citations in context

<a id="k25"></a>

- **Stage:** [Context](../stages/context.md)
- **Category:** [Maintenance and reuse of context](../stages/context.md#k-category-4)
- **Operating Mode:** Drafting
- **Especially Relevant To:** Documents and Decisions, Regulated Systems, Product Development

## Opportunity

AI can link each important piece of information in a context package to a concrete source location and clearly mark conclusions. It makes clarifications faster and makes it possible to check whether a later incorrect result was due to the source, the sample or the agent's interpretation.

## Inputs and Evidence

Available source documents, file revisions, paragraph identities, and in-context citation standards.

## Prerequisites

Sources that can be referenced precisely and a process for spot-checking important claims.

## Example and Deliverable

A rule extract is supplied with a claim identifier, file version and cited section, while the agent's own interpretation is provided separately as a proposal that must be confirmed.

## Safeguards and Review

The references are checked against actual content; an existing link is not proof that it supports the claim.

## Measuring Impact

Time for controlled information, along with invalid references and claims that the source does not substantiate.

## Applying This Idea

Agree which sources, access and quality requirements apply to the specific task. Measure both the time to usable context and rework due to deficiencies or errors in the foundation.
