# P03 Discover friction in the user journey

<a id="p03"></a>

- **Stage:** [Problem](../stages/problem.md)
- **Category:** [User needs and business problems](../stages/problem.md#p-category-1)
- **Operating Mode:** Advisory
- **Especially Relevant To:** Product Development, Mobile and Client Software, Packaged Software

## Opportunity

AI can compare event data, user tests and support cases to point out steps where users interrupt or repeat actions. The result is suggestions for problem areas that should be investigated, with a clear distinction between registered patterns and explanations for them.

## Inputs and Evidence

Event definitions, anonymised user history, funnel measurements, relevant user tests and known errors in the instrumentation.

## Prerequisites

Stable event names, understandable user journey and access to qualitative evidence beyond click data alone.

## Example and Deliverable

Many users return from payment to the address field. AI creates a map of friction points and suggests which processes the team should investigate manually.

## Safeguards and Review

The product owner and analyst check the tracking, the traffic mix and alternative explanations before a pattern is referred to as a user problem.

## Measuring Impact

Measure time to confirmed friction point, along with proportion of suggestions actually supported by user tests.

## Applying This Idea

Use the idea to define a problem with sources, consequence and responsible owner. Also follow up on whether the completed problem basis later leads to relevant work and better outcomes.
