# O02 Discover where user tasks stop

<a id="o02"></a>

- **Stage:** [Observation](../stages/observation.md)
- **Category:** [Users and business outcomes](../stages/observation.md#o-category-1)
- **Operating Mode:** Advisory
- **Especially Relevant To:** Product Development, Mobile and Client Software

## Opportunity

AI can analyze sequences in the user journey and group descriptions of interrupted tasks. It suggests which forms, errors or transitions should be investigated more closely, and links the observations to specific improvement hypotheses rather than simply reporting the number of page views.

## Inputs and Evidence

Aggregated funnel data, error codes, sequence of events and consent-based qualitative feedback.

## Prerequisites

Coherent measurement of task progress and a definition of successful completion.

## Example and Deliverable

An application run loses users by attachment. AI delivers a dropout analysis with likely explanations and questions for the next user test.

## Safeguards and Review

The UX manager checks representative cases. An interruption is not necessarily an error, and the cause must be investigated.

## Measuring Impact

Degree of completion for the user task and time until the cause of withdrawal is clarified, with control of misinterpreted interruptions.

## Applying This Idea

Link the measurement to the agreed hypothesis and actual exposure to the measure. Show data gaps, alternative explanations and uncertainty before an observed change is referred to as an effect.
