# K21 Notify about stale context

<a id="k21"></a>

- **Stage:** [Context](../stages/context.md)
- **Category:** [Sources of data and work surface](../stages/context.md#k-category-3)
- **Operating Mode:** Bounded Execution
- **Especially Relevant To:** Integrations, Platform Engineering, Documents and Decisions

## Opportunity

AI can compare source versions and change history with context packages that are already in use. It can suggest which packages need to be updated or blocked, so that agents do not continue on requirements and interfaces that have changed.

## Inputs and Evidence

Versioned context packages, source identities, change events, owners, and agreed validity.

## Prerequisites

Source versions and links between context packages and assignments must be able to be registered and read.

## Example and Deliverable

When an API form is changed, AI creates a list of affected agent assignments and proposes new extracts, clearly marking the changed contract.

## Safeguards and Review

Owner approves semantic updates; active assignments must follow an agreed stop or resume rule in case of critical changes.

## Measuring Impact

Share of tasks with obsolete context and update time, balanced with unnecessary interruptions and translated changes.

## Applying This Idea

Agree which sources, access and quality requirements apply to the specific task. Measure both the time to usable context and rework due to deficiencies or errors in the foundation.
