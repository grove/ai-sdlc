# L10 Renew context with verified knowledge

<a id="l10"></a>

- **Stage:** [Learning](../stages/learning.md)
- **Category:** [Maintain knowledge and competence](../stages/learning.md#l-category-2)
- **Operating Mode:** Drafting
- **Especially Relevant To:** Legacy Systems, Integrations, Documents and Decisions

## Opportunity

AI can suggest which new decisions, contracts and experiences should be included in the context package for upcoming tasks. It links each update to an authoritative source and suggests the removal of outdated content so that past errors are not passed on as truth.

## Inputs and Evidence

Approved ADRs, updated interfaces, verification findings, source versions and context events.

## Prerequisites

Versioned context and known owners for the sources to be updated.

## Example and Deliverable

An integration has received new error handling. AI creates a versioned change in the context package with source reference, example and replaced text.

## Safeguards and Review

Context owner approves the update. The agent's own claim is not an authoritative source, and access limits must follow the content.

## Measuring Impact

Reduction in confirmed context errors, with timeliness, correct source use and maintenance efforts.

## Applying This Idea

Turn the learning into a concrete measure with owner and follow-up date. Keep negative findings and test the change before using it as a new standard or scaling it to more tasks.
