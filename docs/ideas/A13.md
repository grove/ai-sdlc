# A13 Prepare reversible data migrations

<a id="a13"></a>

- **Stage:** [Agent Execution](../stages/agent-execution.md)
- **Category:** [Maintenance and modernization](../stages/agent-execution.md#a-category-2)
- **Operating Mode:** Drafting
- **Especially Relevant To:** Data and Analytics, Legacy Systems, Regulated Systems

## Opportunity

AI can create proposals for migration scripts, reconciliation queries and control steps for a clarified form change. It can highlight data that requires special treatment, and make both moving forward and possible recovery concrete before anything is performed on real data.

## Inputs and Evidence

Source and target schema, data quality profile, transformation rules, operating limits and requirements for return.

## Prerequisites

Documented data rules, representative test basis and a realistic plan for backup or recovery.

## Example and Deliverable

A name field must be shared; the agent creates a migration draft, discrepancy table for ambiguous values, and queries that compare counts and key relationships.

## Safeguards and Review

Data owner approves the rules; scripts are tested on approved test data and destructive execution requires separate operational authorization.

## Measuring Impact

Time to approved migration package, along with reconciliation discrepancies, data loss and necessary manual correction work.

## Applying This Idea

Define the deliverable, tools, file areas, stop signals and responsibility for review. Include setup, human follow-up and later error correction when the experiment is evaluated.
