# K26 Find discrepancies between code and documentation

<a id="k26"></a>

- **Stage:** [Context](../stages/context.md)
- **Category:** [Maintenance and reuse of context](../stages/context.md#k-category-4)
- **Operating Mode:** Advisory
- **Especially Relevant To:** Integrations, Legacy Systems, Documents and Decisions

## Opportunity

AI can compare documented interfaces, configurations and architecture descriptions with actual code and artifacts. It can suggest which deviations need to be investigated before the task starts, so that the agent does not build on outdated or conflicting descriptions.

## Inputs and Evidence

Source code, published contracts, configuration basis, documentation and information about the current version.

## Prerequisites

Access to comparable versions and owners who can decide what to correct.

## Example and Deliverable

A library documents a return format that the code no longer uses; AI supplies a nonconformance list with location, proposed clarification and affected examples.

## Safeguards and Review

Owner determines which source is correct; code is not automatically concluded if it violates an approved requirement.

## Measuring Impact

Deviations found before execution and reduced clarification time, balanced with false deviations and subsequent contract errors.

## Applying This Idea

Agree which sources, access and quality requirements apply to the specific task. Measure both the time to usable context and rework due to deficiencies or errors in the foundation.
