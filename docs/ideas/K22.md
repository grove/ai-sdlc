# K22 Prepare a reproducible working environment

<a id="k22"></a>

- **Stage:** [Context](../stages/context.md)
- **Category:** [Sources of data and work surface](../stages/context.md#k-category-3)
- **Operating Mode:** Drafting
- **Especially Relevant To:** Platform Engineering, Legacy Systems, Embedded and OT

## Opportunity

AI can read build instructions, dependencies, and environmental requirements to suggest an isolated setup that fits the task. It reduces startup time and makes execution and error reporting more comparable between developers, agents and later verification.

## Inputs and Evidence

Build files, lock files, environment requirements, test commands, allowed images and network access rules.

## Prerequisites

Approved driving surfaces and someone responsible for which dependencies and network calls the environment allows.

## Example and Deliverable

A new developer gets a draft container setup with known dependencies and startup commands, as well as a report of missing tools and unavailable services.

## Safeguards and Review

Platform owner approves driving and photos; commands from the repo are treated as code and run with limited privileges.

## Measuring Impact

Time to first working build, together with environmental deviations, start-up errors and security findings in the setup.

## Applying This Idea

Agree which sources, access and quality requirements apply to the specific task. Measure both the time to usable context and rework due to deficiencies or errors in the foundation.
