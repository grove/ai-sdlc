# A02 Build a prototype to investigate an idea

<a id="a02"></a>

- **Stage:** [Agent Execution](../stages/agent-execution.md)
- **Category:** [Product and user interfaces](../stages/agent-execution.md#a-category-1)
- **Operating Mode:** Drafting
- **Especially Relevant To:** Product Development, Mobile and Client Software, Documents and Decisions

## Opportunity

AI can turn an approved solution proposal into an executable prototype with representative screenshots and simulated data. It can make assumptions concrete and give the project something to try, demonstrate or discard before extensive implementation begins.

## Inputs and Evidence

Limited questions, sketches, user flow, synthetic data and criteria for what the prototype should illustrate.

## Prerequisites

A clear question and agreed boundary between demonstration, user testing and finished product.

## Example and Deliverable

A team will investigate a simpler ordering flow; the agent creates a clickable prototype and an overview of which parts have been simulated.

## Safeguards and Review

Product Owner assesses the learning value; the prototype is clearly marked and does not become production code without separate requirement clarification and control.

## Measuring Impact

Time to a usable test object, together with clarified assumptions and cost of any conversion.

## Applying This Idea

Define the deliverable, tools, file areas, stop signals and responsibility for review. Include setup, human follow-up and later error correction when the experiment is evaluated.
