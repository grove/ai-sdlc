# O12 Display aborted and failed agent attempts

<a id="o12"></a>

- **Stage:** [Observation](../stages/observation.md)
- **Category:** [Delivery flow and resource use](../stages/observation.md#o-category-2)
- **Operating Mode:** Advisory
- **Especially Relevant To:** AI in the product, Platform Engineering, Product Development

## Opportunity

AI can also collect rejected drafts, repeated runs and tasks that had to be taken over manually. The analysis prevents the effect from being assessed only on successful demonstrations, and points to which task types require many attempts before a delivery can be approved.

## Inputs and Evidence

Complete driving logs with outcome, cost, stop events, manual takeover and task category.

## Prerequisites

Run identifiers and logging that includes errors, interruptions and human override.

## Example and Deliverable

A code agent works effectively on approved PRs. AI creates an outcome report that includes failed attempts and time spent on rescue.

## Safeguards and Review

The platform owner checks that all attempts are included. Do not save sensitive raw prompts when metadata is sufficient.

## Measuring Impact

Total time and cost per accepted task, with proportion of interrupted runs and serious agent deviations.

## Applying This Idea

Link the measurement to the agreed hypothesis and actual exposure to the measure. Show data gaps, alternative explanations and uncertainty before an observed change is referred to as an effect.
