# K31 Test if the context package is usable

<a id="k31"></a>

- **Stage:** [Context](../stages/context.md)
- **Category:** [Maintenance and reuse of context](../stages/context.md#k-category-4)
- **Operating Mode:** Bounded Execution
- **Especially Relevant To:** Regulated Systems, AI in the product, Documents and Decisions

## Opportunity

AI can propose and run limited control queries against a context package to uncover missing information and contradictions. The tests provide a more concrete basis for start-up than a general assessment of whether the package looks comprehensive enough.

## Inputs and Evidence

Context package, list of requirements, known control questions, previous errors and expected referrals.

## Prerequisites

Representative control questions and an academic basis with which the answers can be compared independently.

## Example and Deliverable

Before the agent receives a migration, the package is tested against issues of reversal, data keys and downtime; the result is a blank list of sources and clarification needs.

## Safeguards and Review

Human approves important answers and references; an internal score must be validated against real task outcomes before it is used as a gate.

## Measuring Impact

Proportion of tasks stopped by context gaps, balanced by control work and errors that the control questions did not catch.

## Applying This Idea

Agree which sources, access and quality requirements apply to the specific task. Measure both the time to usable context and rework due to deficiencies or errors in the foundation.
