# L17 Improving agent instructions through controlled trials

<a id="l17"></a>

- **Stage:** [Learning](../stages/learning.md)
- **Category:** [Improve agents and work tools](../stages/learning.md#l-category-3)
- **Operating Mode:** Drafting
- **Especially Relevant To:** AI in the product, Platform Engineering, Product Development

## Opportunity

AI can propose limited changes to instructions based on specific errors, and design variants that can be tested on the same evaluation tasks. The experiments show whether a formulation actually helps, instead of the fact that increasingly longer instructions are assumed to provide better quality.

## Inputs and Evidence

Versioned instructions, confirmed errors, representative evaluation set and measurements of cost and quality.

## Prerequisites

A versioned baseline and evaluation tasks that do not simply repeat examples from the instruction.

## Example and Deliverable

An agent overlooks negative tests. AI creates an instruction variant and an evaluation plan that compares test relevance, time and error outcomes.

## Safeguards and Review

Subject owner approves the change after evaluation. Keep test tasks that are kept out of the fit and check that other properties do not deteriorate.

## Measuring Impact

Correct task solution on an independent evaluation set, with cost, duration and new errors as control targets.

## Applying This Idea

Turn the learning into a concrete measure with owner and follow-up date. Keep negative findings and test the change before using it as a new standard or scaling it to more tasks.
