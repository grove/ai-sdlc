# A16 Prepare for removal of unused functionality

<a id="a16"></a>

- **Stage:** [Agent Execution](../stages/agent-execution.md)
- **Category:** [Maintenance and modernization](../stages/agent-execution.md#a-category-2)
- **Operating Mode:** Bounded Execution
- **Especially Relevant To:** Legacy Systems, Maintenance, Platform Engineering

## Opportunity

AI can find possible remnants of decommissioned functions and make a limited proposal for cleanup in code, configuration and documentation. It can connect affected artifacts so that decommissioning is more complete and future maintenance has less to deal with.

## Inputs and Evidence

Approved decommissioning decision, usage signals, code dependencies, flag overview and preservation requirements.

## Prerequisites

A formal decision on retirement and a sufficient overview of consumers and conservation requirements.

## Example and Deliverable

An old feature flag must go; the agent delivers a PR that removes dead code branches and updates documentation, listing conditions that still need to be checked.

## Safeguards and Review

Service Owner confirms that the feature can be removed; lack of observed calls is not alone proof that no one is using it.

## Measuring Impact

Time to complete cleanup, along with recovery needs, hidden dependencies, and reduced future maintenance effort.

## Applying This Idea

Define the deliverable, tools, file areas, stop signals and responsibility for review. Include setup, human follow-up and later error correction when the experiment is evaluated.
